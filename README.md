Analisis dan Visualisasi Sentimen Pengguna/Feedback Aplikasi Menggunakan Grafik Interaktif

Skenario & Latar Belakang

Dalam bidang Interaksi Manusia dan Komputer (HCI), memahami umpan balik (feedback) pengguna sangat penting untuk mengevaluasi kegunaan (usability) sebuah aplikasi. Kita akan membuat script Python untuk memproses data ulasan pengguna dan menghasilkan ringkasan visual berupa grafik distribusi kepuasan.
